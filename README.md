# BeeSimulator

> 3D bee simulator — helicopter flight, foraging, predators, biomes, skill tree, co-op.

---

## In one sentence

You pilot a bee in an open world centered on your hive. You forage flowers to fill your body
with pollen, fly back to deposit it while avoiding (or fighting) predators, and invest the
accumulated pollen into a skill tree that **defines your role** — Tank, Offense or Speed.
Solo or co-op in the same hive, in 5-minute sessions.

## The pillar

**Flight is the game.** Everything else is calibrated against how flying feels. If piloting
the bee is not fun on its own, no enemy, no biome and no skill tree will save the project.
Flight is therefore the first workstream and the exit criterion of phase 1.

## Getting started

```bash
git lfs install     # once per machine — the .glb assets are stored via Git LFS
npm install
npm run dev         # http://localhost:5173
```

| Command | Purpose |
|---|---|
| `npm run dev` | Dev server with hot reload |
| `npm run build` | Typecheck, then production build |
| `npm run test` | Unit tests (simulation layer) |
| `npm run lint` | ESLint, including the architecture boundary rules |
| `npm run assets` | Rebuild the 3D assets in Fiend and pull the GLBs |
| `npm run assets:pull` | Refresh local GLB copies only, without rebuilding |
| `npm run verify` | Download every GLB and assert its structure |

> **Git LFS is required.** Without it, `public/assets/*.glb` check out as small text pointer
> files and the game fails at load with a GLTFLoader parse error that gives no hint at the
> real cause.

> `npm run assets` additionally needs the Fiend write secret in `tools/fiend.config.json`
> (git-ignored). Everyone else just uses the committed GLBs.

## Stack

- **Rendering**: Three.js r186 via Vite
- **Language**: TypeScript, strict mode
- **3D assets**: generated by `tools/build-assets.mjs` into a **Fiend** scene → GLB
- **Scenery**: procedurally generated in code (low-poly, instanced)
- **Persistence**: `localStorage` (solo), authoritative server planned (co-op)
- **Tests**: Vitest
